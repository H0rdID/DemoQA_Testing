# Техническое задание на тестирование DemoQA

## 1. Цель и задачи сайта

**Цель сайта:** Предоставить учебную среду для отработки навыков тестирования веб-приложений.

**Задачи тестирования:**
- Проверить функциональность всех UI-элементов
- Найти и задокументировать дефекты
- Составить чек-лист и тест-кейсы
- Написать автоматизированные тесты

## 2. Целевая аудитория сайта

| Категория | Описание |
|-----------|----------|
| QA-инженеры | Отработка навыков тестирования |
| Студенты | Выполнение учебных заданий |
| Преподаватели | Демонстрация примеров |
| Разработчики | Отладка UI-компонентов |

## 3. Проблемы, которые решает приложение

| Проблема | Решение |
|----------|---------|
| Нет безопасного места для тестов | DemoQA — специальная песочница |
| Сложно найти разные UI-элементы | Всё собрано в одном месте |
| Нет полигона для сложных сценариев | Drag-and-drop, alerts, iframe |

## 4. Аналоги и сравнение

| Критерий | DemoQA | SauceDemo | OpenCart |
|----------|--------|-----------|----------|
| Разнообразие UI-элементов | ✅ много | ✅ мало | ✅ среднее |
| Всплывающие окна (alerts) | ✅ | ❌ | ❌ |
| Drag-and-drop | ✅ | ❌ | ❌ |
| Виджеты (календарь, слайдер) | ✅ | ❌ | ❌ |
| Не требует регистрации | ✅ | ✅ | ❌ |

**Вывод:** DemoQA — лучший выбор для учебного тестирования.
