# Тестирование веб-приложения DemoQA

## Краткое описание сайта
**DemoQA** — это демонстрационный сайт-песочница для тестирования веб-приложений. Содержит множество UI-элементов: формы, чекбоксы, радио-кнопки, таблицы, всплывающие окна, виджеты (календарь, слайдер), drag-and-drop и многое другое.

**Сайт для тестирования:** https://demoqa.com/
