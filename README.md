# Тестирование веб-приложения DemoQA

## Краткое описание сайта
**DemoQA** — демонстрационный сайт-песочница для тестирования веб-приложений. 
Содержит формы, чекбоксы, радио-кнопки, таблицы, всплывающие окна, виджеты (календарь, слайдер), drag-and-drop.

**Сайт для тестирования:** https://demoqa.com/
